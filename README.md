# Диплом любой ценой — Android

Android-сборка игры [trygoatzm/tp-project](https://github.com/trygoatzm/tp-project) с сенсорным управлением.

Готовый APK: вкладка **Actions** → последний запуск **Build APK** → внизу **Artifacts** → `diplom-apk`.

Управление на телефоне:
- левая половина экрана — джойстик движения;
- правая половина — тянуть пальцем в сторону выстрела;
- кнопка **E** рядом с NPC — поговорить, касание экрана листает диалог;
- кнопка **||** сверху справа или «Назад» — в меню.
