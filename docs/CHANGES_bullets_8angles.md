# Изменения в логах: пули в 8 положениях

Заменяет раздел о пулях во всех прежних логах (старый формат `fx_bullet_l<N>_<who>_<кадр>`, 32×16, больше не существует).

## Новый формат

Ключ: `fx_bullet_l<уровень>_<player|boss>_<угол>_<кадр>`
- уровень 1–3; владелец `player` (герой) или `boss`; кадр 1 или 2 (мерцание, 8 раз в секунду)
- угол (против часовой): **0 вправо, 45 вправо-вверх, 90 вверх, 135, 180 влево, 225, 270 вниз, 315**
- файл **32×32** (был 32×16), рисуется 1:1, центр картинки = центр снаряда, блит в `(x-16, y-16)`
- всего 96 ключей (3 × 2 × 8 × 2); пуля уже повёрнута в файле, в коде не вращать
- при 135°/180°/225° текст вверх ногами: это честный поворот

## Код в `projectile.py` (вместо старого)

```python
import math
from src.systems.assets import get_image
who = "player" if self.owner == "player" else "boss"
ang = round(math.degrees(math.atan2(-self.vy, self.vx)) / 45) * 45 % 360  # 0 вправо, 90 вверх
n = int(self.age * 8) % 2 + 1
surface.blit(get_image(f"fx_bullet_l{level}_{who}_{ang}_{n}", (32, 32)), (self.x - 16, self.y - 16))
```
