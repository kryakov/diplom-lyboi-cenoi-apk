# Роль 7. Интерфейс и звук

Лог художника для роли «Интерфейс». Общий справочник: `docs/ART_LOG.md`, стиль: `docs/ART.md`, данные: `docs/art_info.json`. Все числа измерены по картинкам и коду `main`.

`src/ui/hud.py` уже совпадает с картинками (`BAR_SIZE = (320, 44)`, `BAR_POS = (16, 12)`, `HIT_FRAMES = 6`, `FRAME_TIME = 0.05`). Нужно только, чтобы `GameScene` создавал `Hud` (задача роли 1).

## Ключи

`ui_health_0` … `ui_health_5` (обычное состояние), `ui_health_hit_<n>_<k>` (n = 0…4 жизней осталось после удара, k = 1…6), `ui_health_bar` (= `ui_health_5`). Все 320×44.

## Пиксели на экране при `BAR_POS = (16, 12)`

- Файл занимает x 16–335, y 12–55. Полоска x 58–325, y 23–44. Раскрытая зачётка с оценкой x 26–55, y 19–48.
- 5 секций по ~53 px, разделители 2 px. Заливка слева направо.
- Тряска и красная вспышка нарисованы в кадрах попадания, в коде ничего трясти не нужно.

| n жизней | Оценка в зачётке | Заливка |
|---|---|---|
| 5 | 10 (зелёные цифры) | зелёная |
| 4 | 8 (зелёные) | зелёная |
| 3 | 6 (жёлтые) | жёлтая |
| 2 | 4 (оранжевые) | оранжевая |
| 1 | 2 (красные) | красная |
| 0 | 0 (красные, зачётка серая) | пусто |

Слева от полоски нарисована раскрытая зачётка (красная обложка по краю, две страницы; на правой странице оценка); оценка = число жизней × 2. В кадрах попадания обложка зачётки светлеет, оценка уже новая.

Кадры попадания идут по 0,05 с (всего 0,3 с), потом снова `ui_health_<n>`; кадр 6 совпадает с обычным. Шкала перекрывает левый верхний угол комнаты: важные детали фонов туда не ставились.
