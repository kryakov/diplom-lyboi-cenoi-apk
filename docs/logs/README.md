# Логи по ролям

Короткие файлы: в каждом только то, что нужно этой роли, с ключами, числами и готовым кодом.

| Файл | Роль | Что делает |
|---|---|---|
| `ROLE_1_teamlead.md` | 1. Тимлид | `game_scene.py`, `room_view.py`: порядок отрисовки, шкала здоровья, NPC, серые стены |
| `ROLE_2_architect.md` | 2. Архитектор | `FORMAT.md`: схема ключей картинок |
| `ROLE_3_levels.md` | 3. Уровни | `data/rooms/*.json`: фоны, стены, двери, спавн, позиции, карты комнат |
| `ROLE_4_player.md` | 4. Игрок и бой | `player.py`: анимация героя, точка вылета снаряда |
| `ROLE_5_enemies.md` | 5. Враги и боссы | `enemy.py`, `boss.py`, `data/enemies/*.json`: анимации, ворон ВШЭ, имена, `boss_commission` |
| `ROLE_6_story.md` | 6. Сюжет | кто как выглядит, что поменялось для диалогов |
| `ROLE_7_ui.md` | 7. Интерфейс | шкала здоровья: координаты и кадры |

Общее для всех:
- Ключ картинки = имя файла без `.png`, путь в `assets/manifest.json` вида `images/<ключ>.png`. Всего ключей: 894.
- Клетка 30×30 px, комната 32×18 клеток = 960×540. Центр клетки `(cx*30+15, cy*30+15)`.
- Якорь спрайта: центр картинки = центр объекта `(x, y)`; блит в `(x - size/2, y - size/2)`.
- Размеры в игре: герой 20×20, враг 24×24, босс 56×56, NPC 30×30. Файлы 32×32 и 64×64 (боссы).
- Спрайты не отражаются в коде: для каждого из 8 направлений своя картинка.
- Направление: `dir8(dx, dy)`: `DIRS = ["e","se","s","sw","w","nw","n","ne"]; a = degrees(atan2(dy, dx)) % 360; DIRS[int((a + 22.5)//45) % 8]`.
