# Роль 6. Диалоги и сюжет

Лог художника для роли «Сюжет». Общий справочник: `docs/ART_LOG.md`, стиль: `docs/ART.md`, данные: `docs/art_info.json`. Все числа измерены по картинкам и коду `main`.

Что нарисовано и как выглядит (чтобы реплики не противоречили картинкам). Все персонажи вымышленные.

| Кто | Где | Как выглядит |
|---|---|---|
| Герой | везде | студент, каштановые волосы, бирюзовая куртка, жёлтый рюкзак, красная зачётка |
| Дворник | `l1_entrance` | синяя вязаная шапка, оранжевый жилет, седые усы, метла |
| Лаборант | `l2_entrance` | растрёпанные волосы, очки, белый халат, колба с зелёной жидкостью |
| Староста | `l3_entrance` | чёрные волосы, очки, синяя куртка, красный журнал |
| Грамматический страж | враг Печерки | красный шлем с пером, перо в руке |
| Нулевик | враг Родионова | красная куб-голова, оранжевое тело с цифрами 0 1 0 |
| Интегралыч | враг Львовки | оранжевая голова, тело — белый лист со знаком ∫ |
| Ворон ВШЭ (маскот) | враг на всех уровнях | серый ворон с чёрным хохолком и огромным жёлто-оранжевым клювом; стреляет из клюва (открывает и закрывает его) |
| Учительница английского | босс Печерки (`boss_level1`) | сливовые волосы с пучком, очки, фиолетовый кардиган, красный шарф, красная книга; стреляет страницами |
| Хозяин сервера | босс Родионова (`boss_level2`) | фиолетовый монитор-голова с красными глазами, антенна, руки-кабели |
| Препод по матану | босс Львовки (`boss_level3`) | седая шевелюра, очки, усы, коричневый пиджак, красный галстук, мел |

Что поменялось:
- Босс Печерки теперь **Учительница английского**, а не Страж стройки. Нужно имя в `data/enemies/boss_level1.json` и сверить реплики `l1_boss_intro.json`.
- Босс Львовки на картинке **препод по матану**, комиссия не рисуется (нужно проверить `l3_boss_intro.json` и концовки на упоминания комиссии).
- В игре появился общий враг, Ворон ВШЭ.
- Комнаты: Печерка — всё на ремонте (леса, мешки, краска); Родионова — самые технологичные классы; Львовка — обычные классы. Залы боссов в стиле экзамена (бланки, таймер, красные отметки), без крови и монстров.
