## Запуск и меню

- [ ] Игра запускается без ошибок в консоли
- [ ] Стрелки меняют пункт меню, Enter на «Играть» начинает игру, на «Выход» закрывает
- [ ] Esc в меню закрывает игру

## Герой

- [ ] Движение стрелками и WASD, по диагонали не быстрее
- [ ] Стрельба кнопкой мыши в сторону курсора, снаряд не пролетает через стены
- [ ] Герой не проходит через стены и закрытую дверь

## Бой и враги

- [ ] Враги идут к герою и обходят стены
- [ ] Удар врага отнимает 1 жизнь, после удара около секунды неуязвимость
- [ ] Смерть героя: комната загружается заново, счётчик пересдач растёт
- [ ] Лечение (зелёный круг) добавляет жизнь и исчезает

## Комнаты и уровни

- [ ] Дверь закрыта, пока живы враги, и открывается после убийства всех
- [ ] Вход в открытую дверь ведёт в следующую комнату
- [ ] На каждом из 3 уровней порядок: вход, бой, босс
- [ ] Ни в одной комнате герой не застревает

## Боссы

- [ ] Босс стреляет веером и делает рывок
- [ ] После убийства босса дверь открывается

## Диалоги и финал

- [ ] Диалоги показываются и листаются Enter
- [ ] Красный диплом при 0 смертей, синий при хотя бы одной
- [ ] Enter на финальном экране возвращает в меню

## Звук

- [ ] Выстрел, попадание, смерть и подбор лечения со звуком
- [ ] Музыка играет и не накладывается при смене комнат
- [ ] Игра работает и без звуковых файлов

## Сборка

- [ ] Diplom.exe запускается без установленного Python
- [ ] В exe работают картинки, звуки и комнаты...
