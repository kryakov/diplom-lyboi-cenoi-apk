## §2.5. Новый раздел

### 2.5. Пули (32×16)

Ключ: `fx_bullet_l<уровень>_<player|boss>_<кадр>`: 3 уровня × 2 владельца × 2 кадра мерцания = 12 ключей. Файл 32×16, в игре рисуется 1:1 (без масштабирования), центр картинки = центр снаряда `(x, y)`. Пуля нарисована летящей вправо, текст читается слева направо.

| Уровень | Пуля героя (`_player`) | Пуля босса (`_boss`) |
|---|---|---|
| 1. Печерка | слово `shoot`, жёлтое | слово `shoot`, красное с оранжевыми искрами |
| 2. Родионова | нули и единицы `1010` / `0101`, голубые, зелёные помехи | те же цифры, красные, янтарные помехи и красные сбои строк |
| 3. Львовка | производная `f'(x)`, белая (мел), голубая пыль | та же производная, красная, белая пыль |

Кадры 1 и 2 чередовать 8 раз в секунду (мерцание: текст на 1 px ниже, искры и помехи в других местах; у Родионова цифры `1010` ↔ `0101`).

Габариты видимой части (от центра кадра, px; правая и нижняя границы не включают последний пиксель):

Хитбокс в коде не меняется (`Projectile.radius`, 4–5 px вокруг центра): картинка шире хитбокса, это только вид. Текст не поворачивать (читается); при стрельбе вверх и вниз пуля летит горизонтальным словом. Код для `projectile.py`:

```python
# в __init__: self.age = 0.0; в update: self.age += dt
def draw(self, surface, level):  # level = state.level_index + 1
    from src.systems.assets import get_image
    who = "player" if self.owner == "player" else "boss"
    n = int(self.age * 8) % 2 + 1
    img = get_image(f"fx_bullet_l{level}_{who}_{n}", (32, 16))
    surface.blit(img, (self.x - 16, self.y - 8))
```

`CombatSystem.draw` передаёт уровень (`state.level_index + 1`) в `p.draw`. Если ключа нет, `get_image` вернёт заглушку; запасной вариант — прежний кружок.

## §5. Шкала здоровья (изменённые пункты)

- **Положение внутри файла:** сама шкала 300×30 лежит со сдвигом (10, 7), запас под тряску. При `BAR_POS = (16, 12)` на экране: **полоска** x 58–325, y 23–44, **раскрытая зачётка** x 26–55, y 19–48. Весь файл занимает x 16–335, y 12–55.
- Слева от полоски **раскрытая зачётка** (красная обложка по краю, две страницы, корешок; на левой странице строчки, на правой оценка): 5 делений шкалы, оценка от 10 до 0 с шагом 2. Цвет заливки и оценка по числу жизней `n`:

| n жизней | Оценка в зачётке | Заливка |
|---|---|---|
| 5 | 10 (зелёные цифры) | зелёная (с бликом) |
| 4 | 8 (зелёные) | зелёная |
| 3 | 6 (жёлтые) | жёлтая |
| 2 | 4 (оранжевые) | оранжевая |
| 1 | 2 (красные) | красная |
| 0 | 0 (красные, зачётка серая) | пусто |
- **Кадры попадания `ui_health_hit_<n>_<k>`**, `n` = жизней после удара, проигрывать k = 1…6 по 0,05 с (всего 0,3 с), потом `ui_health_<n>`. Заливка уменьшается от `(n+1)/5` к `n/5` (к кадру 4 уже конечное значение). Сдвиг тряски в пикселях файла, красная вспышка и светлая обложка зачётки (таблица сдвигов тряски k = 1…6 осталась прежней, в колонке «Лицо «ай»» теперь «Обложка зачётки светлее»).
